# Gerador de Orçamentos - Serralheria Alvarez

Este é um aplicativo profissional desenvolvido para a **Serralheria Alvarez**, focado na criação, gestão e exportação de orçamentos de forma rápida e eficiente.

## 🚀 Funcionalidades

- **Geração de Orçamentos:** Preenchimento intuitivo de itens com cálculos automáticos de valores unitários e totais.
- **Duas Vias Automáticas:** Gera automaticamente a **Via do Cliente** (limpa, apenas com valores finais) e a **Via da Empresa** (detalhada, com custos de material e margem de lucro).
- **Banco de Dados Local:**
  - **Clientes:** Salve e pesquise clientes para preenchimento automático.
  - **Produtos/Serviços:** Cadastre itens frequentes com seus respectivos custos e porcentagens de lucro.
  - **Histórico:** Salve orçamentos finalizados para consulta ou reedição posterior.
- **Exportação em PDF:** Gere documentos profissionais prontos para impressão ou envio via WhatsApp/E-mail.
- **Salvamento Automático:** Rascunho salvo em tempo real para evitar perda de dados.
- **Personalização:** Upload de logo da empresa com persistência local.

## 🛠️ Tecnologias Utilizadas

- **React 19**
- **TypeScript**
- **Tailwind CSS** (Estilização moderna e responsiva)
- **Lucide React** (Ícones)
- **Framer Motion** (Animações de interface)
- **jsPDF & html-to-image** (Geração de PDF)
- **LocalStorage** (Persistência de dados sem necessidade de servidor externo)

## 📦 Como Rodar o Projeto

1. **Clone o repositório:**
   ```bash
   git clone https://github.com/seu-usuario/serralheria-alvarez-orcamentos.git
   ```

2. **Instale as dependências:**
   ```bash
   npm install
   ```

3. **Inicie o servidor de desenvolvimento:**
   ```bash
   npm run dev
   ```

4. **Acesse no navegador:**
   O projeto estará disponível em `http://localhost:3000`.
